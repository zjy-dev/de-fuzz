8方法示例：从动态栈种子到确定性的布局违例
检查保护关系，而非只统计 __stack_chk_fail 或比较指令是否出现。
来源：论文 §II-D、§VI；检测过程示意
方法
种子结构（示意，非完整 PoC）
extern void use(char *, unsigned);
void f(unsigned n) {
char buf[n];
use(buf, n);
}
buf < 返回地址 < guard → Fail
1. 触发
保留 VLA 与正常返回路径，开启栈保护。
2. 观测
解析缓冲区、guard 和保存返回地址的相对位置。
3. 判定
若 buf < 返回地址 < guard，覆盖可先到返回地址。
4. 证据
输出相关指令、地址关系和失效路径；约简后复检。
