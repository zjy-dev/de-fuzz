# 契约秩序

以留白和对齐表达关系。相同层级采用相同的轮廓、间距与文字尺度，使读者能沿稳定的阅读方向辨认问题、方法与结果。连接线只承担对应关系，转折和箭头均避开文字。

沿用原报告的浅红、浅黄、浅蓝与浅绿。颜色标识方法分组，文字与编号保留独立的辨识能力。白色背景、细边框和适度圆角适合纸面阅读，不使用阴影、渐变或装饰性图标。

字体层级服从内容：列名、模块标题与解释文字逐级收敛，正文保持足够大的字面。中文使用黑体，英文与编号使用无衬线字体。每一处换行、边距和线端都应经过逐项校准。

整体图保留报告的两个挑战与三项研究内容。判定挑战对应不变量形式化及判定方法，搜索挑战对应定向种子生成；不变量集合支撑原型，两类测试能力汇入原型，原型用于真实缺陷发现及有效性验证。研究目标编号与正文一致。

精细处理最终缩放后的效果：按报告实际插图宽度检查字形、箭头和模块间隔，再检查嵌入 Word 后的图片比例及图题关系。完成后的图应具有清楚、克制且统一的学术表达。
